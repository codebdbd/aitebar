# Задача: указатель положения скрытой панели AiteBar

## Цель

Реализовать компактный указатель рядом с системной областью панели задач Windows, чтобы пользователь всегда понимал, на какой стороне экрана находится скрытая панель AiteBar.

Указатель не должен находиться в скрытом tray-меню Windows 11 и не должен создавать постоянный визуальный шум на краях экрана.

## Перед началом работы

Изучи:

- `architecture.md`
- `DESIGN.md`
- `functions.md`
- `MainWindow.xaml`
- `MainWindow.xaml.cs`
- `Models.cs`
- `AppSettingsService.cs`
- `PanelPositionHelper.cs`
- `NativeMethods.cs`
- текущую реализацию tray icon и показа/скрытия панели

Сначала найди:

- где хранится текущая сторона панели;
- где хранится выбранный монитор;
- где панель меняет сторону после перетаскивания;
- как вызываются `ShowDock()`, `HideDock()` и `ToggleDock()`;
- как приложение реагирует на изменение настроек.

Не дублируй существующую логику панели.

## Требуемое поведение

Создай небольшой указатель, расположенный рядом с системной областью панели задач Windows.

Направление стрелки должно соответствовать текущему положению панели:

- `↑` — панель сверху;
- `↓` — панель снизу;
- `←` — панель слева;
- `→` — панель справа.

Указатель должен обновляться сразу после:

- изменения стороны панели в настройках;
- перетаскивания панели на другой край;
- перемещения панели на другой монитор;
- запуска приложения;
- изменения конфигурации мониторов.

## Внешний вид

Указатель должен быть малозаметным в обычном состоянии:

- размер около `20–24 px`;
- прозрачный фон;
- нейтральная серая стрелка;
- акцентный цвет AiteBar только при наведении;
- без мигания;
- без постоянной анимации;
- без текста рядом;
- без яркой синей заливки;
- стиль должен соответствовать существующей дизайн-системе AiteBar.

Используй уже подключённый шрифт иконок. Не добавляй стороннюю библиотеку только ради стрелки.

## Действия пользователя

### Левый клик

Показать или скрыть основную панель через существующий `ToggleDock()` либо эквивалентный текущий механизм.

### Наведение

Показать tooltip:

```text
AiteBar — панель справа, монитор 2
```

Для основного монитора:

```text
AiteBar — панель сверху, основной монитор
```

### Правый клик

Открыть компактное меню:

- Показать панель
- Положение: справа, монитор 2
- Настройки
- Скрыть указатель

Используй существующий стиль тёмного контекстного меню и текущую систему локализации.

## Размещение

Предпочтительное место — слева от системной области панели задач, рядом с часами и системными значками.

Не внедряй элемент внутрь `explorer.exe` и не изменяй системную панель задач.

Реализуй указатель как отдельное компактное служебное WPF-окно:

- без рамки;
- без кнопки в панели задач;
- без появления в `Alt+Tab`;
- без захвата фокуса;
- без отдельной записи среди открытых окон;
- с корректным позиционированием относительно панели задач.

Если точные границы системной области получить надёжно невозможно, выбери безопасное место рядом с ней, не перекрывая:

- часы;
- сеть;
- звук;
- системные кнопки;
- значки запущенных приложений.

Указатель должен находиться на том мониторе, где расположена панель AiteBar.

## Настройка

Добавь настройку:

```csharp
bool ShowTaskbarPositionIndicator
```

Значение по умолчанию:

```csharp
true
```

Настройка должна:

- храниться в `AppSettings`;
- сохраняться через `AppSettingsService`;
- отображаться в общих настройках программы;
- применяться сразу, без перезапуска;
- скрывать и повторно показывать указатель без создания дубликатов.

Название настройки в интерфейсе:

```text
Показывать указатель положения панели
```

Добавь переводы во все поддерживаемые языки проекта.

## Архитектура

Не помещай всю реализацию в `MainWindow.xaml.cs`.

Предпочтительно создать:

```text
TaskbarPositionIndicatorWindow.xaml
TaskbarPositionIndicatorWindow.xaml.cs
TaskbarPositionIndicatorService.cs
TaskbarGeometryHelper.cs
```

Ответственность:

### `TaskbarPositionIndicatorWindow`

- отображение стрелки;
- hover-состояние;
- tooltip;
- обработка кликов;
- контекстное меню.

### `TaskbarPositionIndicatorService`

- создание единственного экземпляра окна;
- показ и скрытие;
- обновление направления;
- обновление позиции;
- реакция на изменение настроек и мониторов;
- корректное освобождение ресурсов.

### `TaskbarGeometryHelper`

- определение положения панели задач;
- расчёт позиции указателя;
- учёт DPI;
- fallback при невозможности определить точную системную область.

`MainWindow` должен только передавать команды показа панели и уведомлять об изменении положения, если существующих событий недостаточно.

## Технические требования

Обязательно учитывать:

- Windows 10 и Windows 11;
- несколько мониторов;
- разные масштабы DPI;
- изменение разрешения;
- изменение рабочей области;
- перезапуск `explorer.exe`;
- автоматическое скрытие панели задач;
- панель задач на разных мониторах.

Не допускается:

- постоянный частый polling;
- внедрение в Explorer;
- использование абсолютных координат для одного разрешения;
- предположение, что панель задач всегда находится снизу;
- предположение, что монитор всегда один;
- создание нового окна при каждом обновлении;
- дублирование `ShowDock()` или `ToggleDock()`;
- добавление тяжёлых сторонних зависимостей;
- несвязанный рефакторинг проекта.

Указатель не должен мешать автоматическому появлению скрываемой панели задач Windows.

## Обработка ошибок

Если положение панели задач определить не удалось:

- не завершай приложение;
- используй безопасный fallback;
- запиши ошибку через существующий `Logger`;
- не показывай модальное сообщение пользователю.

Ошибка указателя не должна ломать:

- основную панель;
- tray icon;
- горячие клавиши;
- запуск приложения.

## Проверки

Добавь тесты для чистой логики:

- соответствие стрелки значению `DockEdge`;
- расчёт позиции для горизонтальной панели задач;
- расчёт позиции для вертикальной панели задач;
- ограничение координат границами монитора;
- fallback на основной монитор;
- пересчёт при смене стороны;
- пересчёт при смене монитора;
- преобразование координат с учётом DPI.

Выполни:

```powershell
dotnet build .\AiteBar.sln -c Release
dotnet test .\AiteBar.Tests\AiteBar.Tests.csproj -c Release
```

Если стандартный запуск тестов не работает из-за временных WPF-файлов:

```powershell
dotnet vstest .\AiteBar.Tests\bin\Release\net10.0-windows\AiteBar.Tests.dll
```

## Критерии готовности

Задача выполнена, если:

1. Указатель виден рядом с системной областью панели задач.
2. Стрелка показывает фактическую сторону панели.
3. Указатель находится на нужном мониторе.
4. Левый клик показывает или скрывает панель.
5. Tooltip показывает сторону и монитор.
6. Правый клик открывает меню.
7. Указатель можно отключить в настройках.
8. Изменение настройки применяется без перезапуска.
9. Указатель не отображается в `Alt+Tab`.
10. Указатель не забирает фокус у активного приложения.
11. После перезапуска Explorer не создаются дубликаты.
12. Работа указателя не ломает основную панель.
13. Release-сборка проходит.
14. Тесты проходят.
15. В `git diff` нет несвязанных изменений.
