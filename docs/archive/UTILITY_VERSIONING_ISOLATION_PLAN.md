# План: Версионирование и изоляция ошибок утилит

## 1. Версионирование контрактов

**Цель:** Старые утилиты работают с новым ядром, новые утилиты — со старым.

**Реализация:**
```csharp
// Добавить в IUtility
public interface IUtility
{
    // Существующие成员
    string Id { get; }
    string DisplayNameKey { get; }
    string IconGlyph { get; }
    string IconColor { get; }
    Task LaunchAsync(...);
    
    // Новое
    Version ContractVersion => new(1, 0); // Версия контракта
    bool IsCompatibleWith(Version coreVersion) => true; // Проверка совместимости
}
```

**Этапы:**
1. Добавить `ContractVersion` в `IUtility`
2. Реализовать проверку совместимости в `UtilityRegistry`
3. Логировать несовместимые утилиты вместо краша

---

## 2. Изоляция ошибок

**Цель:** Крах утилиты не закрывает приложение.

**Реализация:**
```csharp
// В UtilityBase<T>.LaunchAsync()
public async Task LaunchAsync(...)
{
    try
    {
        // Существующая логика
    }
    catch (Exception ex)
    {
        Logger.Log(ex);
        TelemetryService.CaptureException(ex, "utility_crash", 
            new Dictionary<string, string?> { ["utility_id"] = Id });
        
        // Показать пользователю вместо краша
        await Dispatcher.InvokeAsync(() =>
        {
            new DarkDialog($"Утилита {Id} временно недоступна").ShowDialog();
        });
    }
}
```

**Этапы:**
1. Обернуть `LaunchAsync` в try/catch в `UtilityBase<T>`
2. Добавить логирование через `Logger` и `TelemetryService`
3. Показать пользователю понятное сообщение
4. Тестировать: имитировать крах утилиты → приложение работает

---

## 3. Тестирование

**Цель:** Убедиться, что изменения работают.

**Тесты:**
1. **Версионирование:**
   - Утилита с версией 1.0 + ядро 1.0 → работает
   - Утилита с версией 1.0 + ядро 2.0 → работает (обратная совместимость)
   - Утилита с версией 2.0 + ядро 1.0 → не работает (логируется)

2. **Изоляция:**
   - Утилита падает → приложение продолжает работу
   - Утилита показывает ошибку → пользователь видит сообщение
   - Остальные утилиты работают

**Команды:**
```powershell
dotnet build .\AiteBar.sln -c Release
dotnet test .\AiteBar.Tests\AiteBar.Tests.csproj -c Release
```

## 5. Результат

**До:**
- Крах утилиты = крах приложения
- Обновление утилиты = возможный крах
- Новые утилиты = риск сломать всё

**После:**
- Крах утилиты = сообщение + продолжение работы
- Обновление утилиты = проверка совместимости
- Новые утилиты = безопасное добавление
