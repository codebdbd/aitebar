# AiteBar Documentation QA Checklist

Этот документ предназначен для разработчиков, QA и технических писателей. Он заменяет разделы полного аудита, которые раньше находились в пользовательском руководстве.

Пользовательская инструкция находится в [USER_MANUAL.md](USER_MANUAL.md). Технические детали находятся в [technical-reference.md](technical-reference.md).

## Цель проверки

Перед релизом нужно убедиться, что пользовательское руководство описывает основные сценарии без технической перегрузки, а техническая документация покрывает внутренние детали, нужные для поддержки продукта.

## Окна и диалоги

Проверить, что документация покрывает:

- главное окно панели;
- окно настройки кнопки;
- окно настроек программы;
- окно Quick Note;
- окно выбора иконки;

- диалоги подтверждений и ошибок;
- окно выбора цвета;
- окно "О программе";
- стандартные системные диалоги открытия файла, выбора папки и сохранения пакета.

## User Manual Release Criteria

- [ ] `USER_MANUAL.md` начинается с описания пользы и быстрого старта.
- [ ] В начале есть содержание.
- [ ] Инструкции написаны глаголами действия: нажмите, выберите, введите, перетащите.
- [ ] В user manual нет полного аудита функций.
- [ ] В user manual нет проверки полноты.
- [ ] В user manual нет внутренних полей модели, если они не видны пользователю.
- [ ] В user manual есть заметные предупреждения о командах, скриптах и импорте.
- [ ] В user manual есть реальные сценарии для разных ролей.
- [ ] В user manual оставлены места под скриншоты.
- [ ] Технические детали доступны в `docs/technical-reference.md`.
