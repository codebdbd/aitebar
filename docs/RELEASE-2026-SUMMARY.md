# AiteBar Release Summary

The current release candidate is **v1.7.5**.

The authoritative pre-release assessment is [release-audit.md](release-audit.md). The current candidate separates custom-button global activation shortcuts from Hotkey action payloads, reports keyboard input failures, enforces settings file-size limits, and includes regression coverage for those paths.

Release remains conditional on completing the manual keyboard matrix and verifying the final installer artifact in the release environment.
