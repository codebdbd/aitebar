# План реализации форматирования QuickNote в стиле Windows 11 Notepad

## Обзор
Реализовать продвинутые возможности форматирования в QuickNote, полностью повторяющие новый блокноте Windows 11.

## 1. Обновить структуру тулбара (QuickNoteWindow.xaml)
- Добавить **dropdown для заголовков** (как в Windows Notepad: Title/H1, Subtitle/H2, Heading/H3, Subheading/H4, Section/H5, Subsection/H6, Body Text)
- Добавить **dropdown для списков** (Bulleted list, Numbered list)
- Добавить **кнопку Strikethrough** (зачёркнутый текст)
- Добавить **кнопку вставки ссылки** (иконка + Ctrl+K)
- Добавить **разделители** между группами кнопок
- Установить **точный порядок кнопок**, как в Windows Notepad: Headings → Lists → Bold → Italic → Strikethrough → Link → Clear formatting

## 2. Обновить логику Markdown (QuickNoteMarkdown.cs)
### 2.1 Заголовки (H1-H6)
- Добавить парсинг строк, начинающихся с `#`, `##`, `###`, etc.
- Добавить рендеринг заголовков с соответствующими размерами шрифта
- Добавить сохранение заголовков в Markdown
- Добавить методы для применения/удаления заголовков к выделенному тексту

### 2.2 Ссылки в стиле `[текст](URL)`
- Добавить парсинг ссылок в формате `[текст ссылки](https://example.com)`
- Добавить рендеринг кликабельных ссылок с синим цветом и подчёркиванием
- Добавить сохранение ссылок в Markdown

### 2.3 Strikethrough (зачёркнутый текст)
- Добавить парсинг зачёркнутого текста в формате `~~текст~~`
- Добавить рендеринг зачёркнутого текста
- Добавить сохранение в Markdown

### 2.4 Сохраняем и обновляем существующие функции
- Bold (`**текст**`)
- Italic (`*текст*`)
- Underline (`<u>текст</u>`)
- Code (`` `текст` ``)
- Списки (маркированные и нумерованные) - теперь через dropdown

## 3. Обновить логику окна (QuickNoteWindow.xaml.cs)
- Добавить обработчик dropdown для заголовков (H1-H6 + Body Text)
- Добавить обработчик dropdown для списков (Bulleted/Numbered)
- Добавить обработчик кнопки Strikethrough
- Добавить обработчик кнопки «Вставить ссылку» (открывать простой диалог ввода текста и URL)
- Добавить поддержку Ctrl+K для вставки ссылки
- Добавить поддержку Ctrl+Shift+X для Strikethrough
- Обновить логику темы, чтобы новые элементы тулбара меняли цвет при смене темы

## 4. Обновить тесты (QuickNoteMarkdownTests.cs)
- Добавить тесты для заголовков (парсинг, сохранение, рендеринг)
- Добавить тесты для ссылок в стиле `[текст](URL)`
- Добавить тесты для Strikethrough (`~~текст~~`)
- Обновить существующие тесты, чтобы они соответствовали новой логике

## 5. Финальная проверка и сборка
- Собрать проект без предупреждений
- Запустить все тесты
- Проверить работу новых функций вручную:
  - Выбор заголовков из dropdown
  - Выбор списков из dropdown
  - Вставка ссылок через кнопку и Ctrl+K
  - Strikethrough через кнопку и Ctrl+Shift+X
  - Сохранение/загрузка в Markdown
  - Работа с темой (светлая/тёмная)
