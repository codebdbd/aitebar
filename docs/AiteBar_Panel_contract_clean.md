# Контракт программы AiteBar Panel

## 1. Назначение

**AiteBar Panel** — простой двухпанельный файловый менеджер для Windows 11.

Цель программы: дать пользователю быстрый интерфейс для базовой работы с файлами и папками в двух панелях, с нативными файловыми операциями Windows и контекстным меню как в Проводнике Windows.

Программа не должна повторять Total Commander и не должна быть комбайном. Нужна только базовая, быстрая и понятная двухпанельная работа с файлами.

## 2. Главный принцип

**AiteBar Panel — две панели и базовые операции, а файловая механика должна работать как в Проводнике Windows.**

Это означает:

- интерфейс: простой двухпанельный файловый менеджер;
- операции с файлами: через нативные механизмы Windows;
- контекстное меню: нативное меню Windows Explorer;
- визуальный стиль: Windows 11 / Fluent Design;
- без лишних функций и перегруженного интерфейса.

## 3. Основной интерфейс

Главное окно состоит из:

1. Заголовка окна с названием **AiteBar Panel**.
2. Левой файловой панели.
3. Правой файловой панели.
4. Нижней панели функциональных кнопок.

Главный экран должен содержать только нужные элементы:

- две файловые панели;
- выбор диска в каждой панели;
- текущий путь;
- информацию о занятом месте на диске;
- список файлов и папок;
- строку состояния выбора;
- нижние кнопки действий.

## 4. Две файловые панели

Программа всегда отображает две панели:

- левая панель;
- правая панель.

Каждая панель показывает отдельный диск или отдельную папку.

Пример:

- левая панель: `C:\Users\User\Documents`;
- правая панель: `D:\Backup`.

Одна панель всегда активная. Команды применяются к активной панели.

Копирование и перемещение выполняются из активной панели в противоположную.

Переключение активной панели:

- `Tab`;
- клик мышью по панели.

## 5. Верхняя часть панели

В верхней части каждой панели отображается:

1. Выбор диска.
2. Текущий путь.
3. Информация о занятом месте на диске.

Формат:

`[C: ▼] C:\Projects     Занято: 103,2 ГБ / 363,1 ГБ`

Информация о диске должна отображаться в гигабайтах.

Предпочтительный формат:

`Занято: 103,2 ГБ / 363,1 ГБ`

Первое значение — занятое место. Второе значение — общий размер диска.

## 6. Выбор дисков

В каждой панели должен быть выпадающий список дисков.

Список показывает доступные устройства:

- локальные диски;
- USB-накопители;
- внешние диски;
- сетевые диски;
- виртуальные диски, если они доступны в системе.

Пример:

- `C: Локальный диск`;
- `D: Данные`;
- `E: USB`;
- `Z: Сетевой диск`.

После выбора диска панель открывает корень выбранного диска, обновляет путь, список файлов и информацию о занятом месте.

## 7. Список файлов и папок

В каждой панели отображается таблица файлов.

Обязательные колонки:

- `Имя`;
- `Тип`;
- `Размер`;
- `Дата`;
- `Атрибуты`.

Для папок в колонке типа показывается:

`<Папка>`

Для файлов показывается расширение или тип:

- `TXT`;
- `EXE`;
- `PNG`;
- `DOCX`;
- `ZIP`;
- `BAT`;
- `PS1`;
- `MD`;
- `JSON`;
- `XML`.

Размер файлов отображается в удобном формате:

- `Б`;
- `КБ`;
- `МБ`;
- `ГБ`.

В начале списка должна быть строка:

`..`

Она используется для перехода на уровень выше.

## 8. Навигация

Пользователь должен перемещаться по файловой системе через клавиатуру и мышь.

Поддержать:

- стрелки вверх/вниз;
- `Enter`;
- `Backspace`;
- двойной клик мышью;
- строку `..`;
- выбор диска.

Поведение:

- `Enter` на папке — открыть папку;
- `Enter` на файле — открыть файл стандартным способом;
- `Backspace` — перейти на уровень выше;
- двойной клик по папке — открыть папку;
- двойной клик по файлу — открыть файл;
- `..` — перейти в родительскую папку.

## 9. Нижняя панель кнопок

Нижняя панель кнопок обязательна.

Кнопки должны быть текстовыми, без иконок, в стиле Total Commander.

Кнопки:

- `F3 Просмотр`;
- `F4 Правка`;
- `F5 Копировать`;
- `F6 Переместить`;
- `F7 Каталог`;
- `F8 Удалить`;
- `Alt+F4 Выход`.

Эта панель всегда видна внизу окна.

## 10. Просмотр файла — F3

`F3 Просмотр` открывает выбранный файл в режиме только для чтения.

Файл нельзя случайно изменить в режиме просмотра.

Для текстовых файлов используется встроенный или системный просмотрщик.

Если формат не поддерживается, файл открывается стандартным способом Windows или показывается понятное сообщение.

## 11. Правка файла — F4

`F4 Правка` открывает выбранный файл для редактирования.

Для текстовых файлов используется встроенный редактор или системный редактор, заданный в настройках.

Если файл нельзя редактировать напрямую, программа предлагает открыть его во внешнем приложении.

## 12. Копирование — F5

`F5 Копировать` копирует выбранные файлы и папки из активной панели в противоположную.

Если выделено несколько файлов, копируются выделенные файлы.

Если ничего не выделено, копируется текущий файл или текущая папка.

Перед копированием показывается окно подтверждения с источником, назначением и кнопками:

- `Копировать`;
- `Отмена`.

Копирование должно выполняться через нативный механизм Windows.

## 13. Перемещение и переименование — F6

`F6 Переместить` перемещает выбранные файлы и папки из активной панели в противоположную.

Если путь назначения тот же, но имя изменено, операция считается переименованием.

Перемещение и переименование должны выполняться через нативные механизмы Windows.

## 14. Создание папки — F7

`F7 Каталог` создает новую папку в активной панели.

После нажатия появляется окно ввода имени папки.

После создания список файлов обновляется автоматически.

## 15. Удаление — F8

`F8 Удалить` удаляет выбранные файлы и папки.

По умолчанию удаление выполняется в корзину Windows.

Перед удалением обязательно показывается подтверждение.

Удаление должно выполняться через нативные механизмы Windows.

## 16. Выход — Alt+F4

`Alt+F4 Выход` закрывает программу.

Если выполняется файловая операция, программа должна предупредить пользователя.

## 17. Нативные файловые операции Windows

AiteBar Panel должен использовать нативные механизмы Windows для:

- копирования;
- перемещения;
- удаления;
- переименования.

Основной технический вариант:

`IFileOperation` / Windows Shell API.

Нельзя использовать самописный copy engine как основной механизм.

Нельзя делать основное копирование через ручной `FileStream`, если это ухудшает скорость и поведение по сравнению с Проводником Windows.

Цель: скорость и поведение файловых операций должны быть максимально близки к Проводнику Windows.

## 18. Асинхронность

Файловые операции должны выполняться в фоне.

Интерфейс не должен зависать при:

- копировании;
- перемещении;
- удалении;
- обработке большого количества файлов;
- открытии больших папок.

Пользователь должен видеть прогресс операции и иметь возможность отменить действие.

## 19. Прогресс операций

Для длительных операций показывается окно прогресса.

Показывать:

- текущий файл;
- общий прогресс;
- источник;
- назначение;
- количество обработанных файлов;
- скорость, если доступна;
- оставшееся время, если доступно.

Кнопка:

- `Отмена`.

## 20. Конфликты файлов

Если файл уже существует в папке назначения, программа должна показать окно конфликта.

Показывать:

- имя файла;
- путь источника;
- путь назначения;
- размер исходного файла;
- размер существующего файла;
- дату изменения исходного файла;
- дату изменения существующего файла.

Варианты действий:

- `Заменить`;
- `Пропустить`;
- `Переименовать`;
- `Отмена`.

Поведение должно быть близким к Проводнику Windows.

## 21. Ошибки файловых операций

При ошибке программа показывает понятное сообщение.

Типовые ошибки:

- нет доступа;
- файл занят другой программой;
- недостаточно места;
- путь слишком длинный;
- диск недоступен;
- сетевой путь недоступен;
- файл уже существует;
- нет прав администратора.

Действия:

- `Повторить`;
- `Пропустить`;
- `Отмена`.

## 22. Контекстное меню Windows

AiteBar Panel должен поддерживать нативное контекстное меню Windows Explorer.

Меню должно вызываться через Windows Shell API.

Меню должно показывать те же системные команды и расширения, что и Проводник Windows:

- открыть;
- открыть с помощью;
- копировать;
- вырезать;
- вставить;
- переименовать;
- удалить;
- свойства;
- команды сторонних программ.

Контекстное меню должно работать для:

- файлов;
- папок;
- нескольких выбранных элементов;
- пустой области панели.

## 23. Правая кнопка мыши

По умолчанию правая кнопка мыши работает для выделения файлов:

- правый клик по файлу — выделить;
- правый клик по выделенному файлу — снять выделение;
- правый клик по папке — выделить или снять выделение.

Контекстное меню Windows вызывается через:

- `Shift + Right Click`;
- `Shift + F10`;
- режим в настройках, если пользователь выбрал правую кнопку для контекстного меню.

Настройка:

`Правая кнопка мыши`

Варианты:

1. `Выделение файлов`;
2. `Контекстное меню Windows`.

По умолчанию: `Выделение файлов`.

## 24. Выделение файлов

Поддержать способы выделения:

- `Space`;
- `Insert`;
- правая кнопка мыши;
- рамка выделения мышью;
- `Ctrl+A`.

Поведение:

- `Space` — выделить или снять выделение текущего файла;
- `Insert` — выделить текущий файл и перейти ниже;
- правая кнопка — выделить или снять выделение без открытия меню;
- `Ctrl+A` — выделить всё;
- `Esc` — снять выделение, если нет активного диалога.

## 25. Текущий файл, выделение и активная панель

Интерфейс должен различать:

- текущий файл;
- выделенные файлы;
- активную панель.

Текущий файл — строка, на которой стоит курсор.

Выделенные файлы — элементы, отмеченные для операции.

Активная панель — панель, к которой применяются команды.

Визуально:

- текущий файл — акцентная строка;
- выделенные файлы — мягкая подсветка или отметка;
- активная панель — акцентная рамка или линия.

## 26. Drag-and-drop

AiteBar Panel должен поддерживать перетаскивание файлов мышью.

Сценарии:

- из левой панели в правую;
- из правой панели в левую;
- внутри одной панели;
- из Проводника Windows в AiteBar Panel;
- из AiteBar Panel в Проводник Windows.

Поведение:

- между разными дисками — копирование;
- внутри одного диска — перемещение;
- `Ctrl` при перетаскивании — копирование;
- `Shift` при перетаскивании — перемещение.

Файловая операция должна выполняться через нативный механизм Windows.

## 27. Строка состояния панели

Внизу каждой панели показывается строка состояния выбора.

Примеры:

`Выбрано: 0 файлов, 0 папок, 0 Б`

`Выбрано: 3 файла, 1 папка, 24,6 МБ`

Строка состояния показывает только информацию о выборе.

## 28. Автообновление

Список файлов должен обновляться автоматически после:

- создания папки;
- удаления;
- копирования;
- перемещения;
- переименования;
- смены диска;
- перехода в другую папку;
- внешнего изменения файлов, если это возможно отследить.

Обновление не должно замедлять интерфейс.

## 29. Горячие клавиши

Обязательные горячие клавиши:

- `F3` — просмотр;
- `F4` — правка;
- `F5` — копировать;
- `F6` — переместить / переименовать;
- `F7` — создать каталог;
- `F8` — удалить;
- `Alt+F4` — выход;
- `Tab` — переключить активную панель;
- `Enter` — открыть файл или папку;
- `Backspace` — перейти на уровень выше;
- `Space` — выделить / снять выделение;
- `Insert` — выделить и перейти ниже;
- `Esc` — отменить действие или снять выделение;
- `Ctrl+A` — выделить всё;
- `Ctrl+D` — открыть выбор диска;
- `Shift+F10` — открыть контекстное меню Windows;
- `Shift+Right Click` — открыть контекстное меню Windows.

## 30. Работа с несколькими файлами

Если выделены файлы, операция применяется к выделенным файлам.

Если ничего не выделено, операция применяется к текущему элементу.

Пример:

- выделено 5 файлов;
- нажато `F5`;
- копируются 5 файлов.

Если ничего не выделено:

- курсор стоит на `report.docx`;
- нажато `F5`;
- копируется только `report.docx`.

## 31. Работа с папками

Программа должна уметь:

- открывать папки;
- создавать папки;
- копировать папки;
- перемещать папки;
- переименовывать папки;
- удалять папки;
- копировать папки со всем содержимым;
- удалять папки со всем содержимым.

Опасные операции должны подтверждаться пользователем.

## 32. Системная интеграция

AiteBar Panel должен корректно работать с Windows 11.

Требования:

- Windows Shell API;
- нативное контекстное меню;
- корзина Windows;
- UAC;
- системное открытие файлов;
- ассоциации файлов Windows;
- сетевые диски;
- USB-диски;
- длинные пути, насколько это возможно;
- корректная работа с Windows Defender.

## 33. Визуальный стиль

Программа должна выглядеть как современное приложение Windows 11.

Стиль:

- Fluent Design;
- темная тема;
- скругленные углы;
- мягкие тени;
- аккуратные границы;
- системный акцентный цвет;
- читаемая типографика;
- спокойные цвета;
- без визуального шума.

Главный приоритет — читаемость, скорость и простота.

## 34. Настройки

Настройки должны быть минимальными.

Минимальные настройки:

1. Тема:
   - темная;
   - светлая;
   - системная.

2. Правая кнопка мыши:
   - выделение файлов;
   - контекстное меню Windows.

3. Удаление:
   - в корзину;
   - окончательное удаление с подтверждением.

4. Файловые операции:
   - использовать нативные механизмы Windows.

5. Drag-and-drop:
   - показывать подтверждение;
   - не показывать подтверждение.

6. Редактор для `F4`:
   - встроенный;
   - системный;
   - выбранное приложение.

## 35. Производительность

Программа должна быстро открываться и быстро реагировать на действия пользователя.

Требования:

- быстрый старт;
- мгновенное переключение панелей;
- быстрый переход по папкам;
- отсутствие зависаний интерфейса;
- асинхронная загрузка больших папок;
- отсутствие пересчета размеров папок без запроса пользователя;
- отложенное обновление интерфейса при больших операциях.

Файловые операции не должны быть медленнее Проводника Windows при обычных сценариях.

## 36. Безопасность операций

Опасные действия должны подтверждаться.

Подтверждать:

- удаление;
- окончательное удаление;
- замену файлов;
- массовое перемещение;
- операции с системными папками;
- операции, требующие прав администратора.

По умолчанию удаление идет в корзину Windows.

## 37. Ограничения интерфейса

В главном окне не должно быть:

- верхнего меню;
- панели инструментов сверху;
- отдельной кнопки обновления;
- нижней командной строки вида `C:\>`;
- лишних кнопок;
- декоративных элементов без функции.

## 38. Критерии готовности

Программа соответствует контракту, если:

1. Есть две файловые панели.
2. Есть выбор диска в каждой панели.
3. Вверху панели отображается путь и занятое место в гигабайтах.
4. Есть нижняя панель текстовых кнопок `F3–F8` и `Alt+F4` без иконок.
5. Нет верхнего меню.
6. Нет отдельной кнопки обновления.
7. Нет нижней командной строки `C:\>`.
8. Работают базовые операции: просмотр, правка, копирование, перемещение, создание папки, удаление.
9. Копирование, перемещение, удаление и переименование выполняются через нативные механизмы Windows.
10. Контекстное меню вызывается как в Проводнике Windows.
11. Правая кнопка мыши может выделять файлы.
12. `Space` выделяет и снимает выделение.
13. Drag-and-drop работает между панелями.
14. Интерфейс не зависает при файловых операциях.
15. Программа визуально соответствует Windows 11.
16. Название программы — **AiteBar Panel**.

## 39. Итоговая формула

**AiteBar Panel — простой двухпанельный файловый менеджер для Windows 11: две панели, базовые операции, текстовые кнопки F3–F8, нативные файловые операции Windows и контекстное меню как в Проводнике.**
