# Подключение AI-сервисов

AiteBar поддерживает внешние AI-сервисы как общий источник моделей для будущих встроенных инструментов. В первой версии доступны OpenRouter, Cerebras, Google Gemini, Groq, GitHub Models и Mistral AI. DeepInfra не поддерживается, потому что у него нет подтверждённой постоянной бесплатной квоты.

## Что уже предоставляет AiteBar

- несколько API-подключений для каждого сервиса;
- приоритет подключений внутри одного сервиса;
- обозначение аккаунта или проекта, которому принадлежит общая квота;
- проверка ключа через загрузку списка моделей без отправки тестового запроса модели;
- автоматический переход к следующей независимой квоте после временного ограничения;
- переход к следующему сервису, если подключения текущего недоступны;
- запрет автоматического fallback на модель, явно обозначенную как платная;
- хранение ключей в Диспетчере учётных данных Windows.

Наличие подключения ещё не заставляет AiteBar отправлять данные в AI-сервис. Текст или файл сможет быть передан только будущей AI-утилитой после явного действия пользователя.

## Добавление подключения

1. Откройте `Настройки программы`.
2. Перейдите в раздел `Нейросети`.
3. Нажмите `Добавить подключение`.
4. Выберите сервис.
5. Введите понятное название, например `Cerebras — личный`.
6. В поле `Аккаунт или проект` укажите группу общей квоты, например `Личный аккаунт Cerebras`.
7. Вставьте API-ключ и нажмите `Добавить`.
8. Нажмите `Проверить`. AiteBar должен показать количество доступных моделей.
9. Нажмите общую кнопку `Сохранить` внизу окна настроек.

После сохранения ключ больше не отображается. Для его замены удалите подключение и добавьте его заново.

## Несколько ключей и общая квота

Несколько ключей не всегда дают несколько лимитов. Если два ключа принадлежат одному проекту или организации, они часто расходуют общую квоту. Для таких ключей укажите одинаковое значение `Аккаунт или проект`. После ответа `429 Too Many Requests` AiteBar временно пропустит всю эту группу, а не станет бесполезно перебирать её ключи.

Примеры:

- два ключа одного Google project: одинаковая группа;
- два ключа одного Groq organization: одинаковая группа;
- два ключа одного Cerebras project: одинаковая группа;
- ключи двух действительно независимых проектов: разные группы.

Стрелки рядом с подключением меняют его приоритет внутри выбранного сервиса. По умолчанию используется верхнее доступное подключение, остальные остаются резервными.

## OpenRouter

1. Откройте [OpenRouter Keys](https://openrouter.ai/keys).
2. Войдите в аккаунт и создайте API key.
3. Добавьте его в AiteBar как `OpenRouter`.

AiteBar загружает `https://openrouter.ai/api/v1/models` и считает гарантированно бесплатными только модели, у которых цены prompt и completion равны нулю. В первую очередь выбирается `openrouter/free`, автоматически направляющий запрос к доступной бесплатной модели.

Дополнительные ключи одного аккаунта не увеличивают общие лимиты бесплатных моделей. Используйте одинаковую quota group.

## Cerebras

1. Откройте [Cerebras Inference Cloud](https://cloud.cerebras.ai/).
2. Зарегистрируйтесь или войдите.
3. Создайте API key в консоли.
4. Добавьте его в AiteBar как `Cerebras`.

Cerebras имеет официальный Free Tier. Точные лимиты зависят от модели и аккаунта. Ответы inference API содержат остаток запросов и время сброса квоты. Ограничения проверяются на уровнях project и organization, поэтому ключи одного проекта должны иметь одинаковую группу.

## Google Gemini

1. Откройте [Google AI Studio API Keys](https://aistudio.google.com/app/apikey).
2. Выберите существующий Google Cloud project или создайте отдельный проект.
3. Создайте API key.
4. Добавьте его в AiteBar как `Google Gemini`.

Лимиты Gemini применяются к проекту, а не к отдельному ключу. Все ключи одного проекта должны иметь одинаковую quota group. Количество запросов в минуту, токенов в минуту и запросов в день зависит от модели и может изменяться. Не используйте старое универсальное значение `1500 запросов в день` как гарантию.

## Groq

1. Откройте [Groq API Keys](https://console.groq.com/keys).
2. Выберите нужный project.
3. Создайте API key.
4. Добавьте его в AiteBar как `Groq`.

Groq имеет Free Plan с лимитами, зависящими от модели. Ключи принадлежат проектам, но организация сохраняет общий верхний предел. Ключи одной организации не следует считать полностью независимыми резервами.

## GitHub Models

1. Откройте [GitHub Personal Access Tokens](https://github.com/settings/personal-access-tokens).
2. Создайте fine-grained personal access token.
3. Разрешите ему `Models: read` (`models: read`). Не выдавайте права на запись в репозитории, если они не нужны для других задач.
4. Добавьте token в AiteBar как `GitHub Models`.

Бесплатная включённая квота связана с GitHub account. Несколько PAT одного аккаунта используют одну квоту и должны иметь одинаковую группу. AiteBar получает актуальный каталог через GitHub Models Catalog API.

## Mistral AI

1. Откройте [Mistral Console](https://console.mistral.ai/api-keys).
2. Убедитесь, что организация работает в Free mode, если вы не хотите расходов.
3. Создайте API key.
4. Добавьте его в AiteBar как `Mistral AI`.

Mistral Free mode предназначен для экспериментов и прототипирования. Лимиты применяются на уровне организации. API возвращает доступные аккаунту модели, но не помечает каждую отдельным полем `free`, поэтому пользователь обязан не включать платный Scale plan для подключения, предназначенного только для бесплатного использования.

## Безопасность ключей

Ключи сохраняются как Generic Credentials с именами `AiteBar/AI/<идентификатор>` в Windows Credential Manager. В `%APPDATA%\Codebdbd\Aite Bar\settings.json` находится только ссылка на credential, название подключения и quota group.

AiteBar не должен:

- записывать ключ в `settings.json`, backup или error log;
- отправлять ключ в Sentry;
- показывать сохранённый ключ повторно;
- автоматически создавать аккаунты или обходить ограничения провайдера;
- переходить к модели, явно определённой как платная.

Удаление подключения и сохранение настроек удаляет соответствующий credential. Добавление подключения с последующим `Отменить` также удаляет временно записанный credential.

## Диагностика

- `Не проверено`: нажмите `Проверить`.
- `HTTP 401`: ключ отсутствует, отозван или введён неверно. Удалите подключение и создайте его заново.
- `HTTP 403`: ключ действителен, но не имеет нужного разрешения. Для GitHub проверьте `models: read`.
- `HTTP 429`: достигнут минутный или дневной лимит. AiteBar применит cooldown к общей quota group.
- `HTTP 402`: у сервиса закончились кредиты или подключённый режим требует оплаты. AiteBar не должен продолжать запросы через это подключение.
- `HTTP 5xx`: временная ошибка сервиса; AiteBar может попробовать следующее подключение.
- `Доступно 0 моделей`: авторизация прошла, но сервис не вернул поддерживаемых chat-моделей. Проверьте тариф, регион и разрешения аккаунта.

Провайдеры вправе менять модели и лимиты. Актуальные значения проверяйте в их личных кабинетах; AiteBar не показывает выдуманный остаток, если сервис не прислал его через API.
