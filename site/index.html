Trust and safety

Useful power tools should be explicit about what they do.

Local-first storage

Settings and data live in the Windows user profile at `%AppData%\Codebdbd\Aite Bar`.

Command awareness

Commands and scripts require confirmation before launch, which matters when your launcher can automate real system actions.

Privacy posture

Sentry crash reporting is disabled by default. It only turns on when explicitly configured for support or development scenarios.

Transparent updates

Update checks point to GitHub releases. AiteBar can open the release page when a newer version is available, without forced auto-install behavior.

FAQ

Questions people ask before adding another tool to their desktop.

What does AiteBar replace?

It replaces scattered bookmarks, desktop shortcuts, launch folders, profile-switching routines, and repeated visits to the same Windows utilities.

Can it launch browser profiles and private windows?

Yes. Web buttons support browser choice, profile selection, app mode where supported, incognito or private mode, fullscreen launch, and profile rotation.

Is this only for developers?

No. The documented use cases already cover marketing, development, design, personal workflows, and any setup where the same destinations need to be reached repeatedly.

Does it work with multiple monitors?

Yes. The panel can be positioned on different edges and different monitors, and that positioning is part of the product behavior described in the app docs.

Can I share my setup?

Yes. Export a context panel as `.aitebarpanel`, then import it on another computer or into another setup.

Where do I get updates?

The latest builds are distributed through the GitHub releases page. The app can also check for updates and open the release page when a newer version exists.
